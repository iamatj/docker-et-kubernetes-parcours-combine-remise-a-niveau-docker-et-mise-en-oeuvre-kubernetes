Le concept

Ce que Compose crée pour vous

$ docker compose up -d
✔ Network huiteo_avant      Created
✔ Network huiteo_arriere    Created
✔ Volume  huiteo_donnees-db Created
✔ Container huiteo-db-1     Healthy
✔ Container huiteo-api-1    Started
✔ Container huiteo-front-1  Started

  • le projet (name: huiteo, sinon le nom du dossier) préfixe tout
  • chaque service devient un nom DNS : l'API joint db
  • Compose n'est qu'un client de l'API Docker : docker ps, docker volume ls voient tout

Les commandes du quotidien

up -d --build · ps · logs -f api · exec db psql … · restart api · down

Ce que Compose ne fait pas

pas de plusieurs machines, pas de relance ailleurs si le serveur tombe, pas de mise à jour sans coupure : c'est le chapitre 5, puis Kubernetes.
