1 · ClusterIP le défaut

Joignable depuis le cluster seulement : un nom DNS (api) et une IP virtuelle stable. kube-proxy choisit un pod, sur n'importe quel nœud. Chez Huiteo : l'API, la base.

2 · NodePort

N'importe quel nœud, port 30000 – 32767, même un nœud sans le pod. Chez Huiteo : le site sur :30080 (TP 06).

3 · LoadBalancer

Une adresse externe : MetalLB dans ce lab, le cloud ailleurs. Elle arrive sur un nœud, puis suit le chemin du NodePort. Le site sur 10.10.0.201 (TP 07).

4 · port-forward pas un Service

Un tunnel de votre poste vers un pod, à travers l'API Server, le temps d'une session. Pour déboguer, jamais pour les clients.

Gigognes : un LoadBalancer crée un NodePort, qui crée un ClusterIP.
