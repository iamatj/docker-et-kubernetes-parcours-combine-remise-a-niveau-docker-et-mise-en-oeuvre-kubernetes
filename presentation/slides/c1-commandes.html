Le récapitulatif

Les commandes Docker à connaître

Conteneurs

docker run -d --name x img

créer et démarrer un conteneur

docker ps · docker ps -a

ceux qui tournent · tous

docker logs -f x

ses sorties, en continu

docker exec -it x sh

ouvrir un shell dedans

docker stop x · docker start x

arrêter (SIGTERM) · relancer

docker rm -f x

supprimer (arrêter avant)

docker inspect x

toute sa fiche, en JSON

Images

docker pull img:tag

télécharger depuis un registre

docker image ls

les images présentes

docker build -t img:tag .

construire depuis un Dockerfile

docker tag img autre:tag

donner un autre nom

docker push img:tag

envoyer vers un registre

docker image history img

ses couches

docker rmi img

supprimer une image

Le moteur

docker version

client et serveur : 2 blocs

docker info

stockage, cgroups, dossier

docker system df

la place occupée

docker system prune

faire le ménage

docker context ls

à quel daemon je parle

systemctl status docker

le service

journalctl -u docker

ses journaux

Volumes, réseaux, Compose

docker volume ls · create

les données qui survivent

docker network ls · create

les réseaux des conteneurs

docker compose up -d

lancer toute l'application

docker compose ps

ses conteneurs

docker compose logs -f

leurs sorties

docker compose down

tout arrêter et supprimer

docker compose config

vérifier le fichier

Options qui reviennent partout : -d en arrière-plan · -it interactif avec un terminal · --rm supprimé à la fin · -p 8080:80 publier un port · -v monter un volume ou un dossier · -e une variable · --help sur chaque commande.
