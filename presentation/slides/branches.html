Le dépôt

Une branche par TP

# le premier jour
git clone https://github.com/iamatj/docker-et-kubernetes-…
cd ~/cordee
git checkout tp-00-prise-en-main

# au début de chaque TP suivant
git fetch
git stash -u
git checkout tp-NN-sujet
kubectl apply -R -f k8s/

Sur la branche tp-NN

l'application dans l'état attendu au début du TP, l'énoncé tp/NN-…/README.md et les corrections des TP précédents.

La correction

solutions/NN-…/, aux mêmes chemins qu'à la racine. k8s/ est l'état de départ, pas la correction.

Rattraper

Changer de branche remet tout le monde au même point : un TP raté ne bloque pas le suivant.

Dépôt : github.com/iamatj/docker-et-kubernetes-parcours-combine-remise-a-niveau-docker-et-mise-en-oeuvre-kubernetes. Les slides sont sur main seulement. git stash -u met de côté le travail du TP précédent sans le perdre.
