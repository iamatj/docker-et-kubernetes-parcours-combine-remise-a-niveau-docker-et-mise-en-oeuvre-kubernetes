les études et les rendez-vous, sur disque

  • HTTP : une requête (GET lire, POST envoyer) et un code de réponse : 200 OK, 404 introuvable, 503 indisponible
  • API : des URL qui répondent des données (JSON) au lieu d'une page : /api/etudes, /api/rendez-vous
  • port : la « porte » sur laquelle un programme écoute
  • variables d'environnement : la configuration (DB_HOST, DB_PASSWORD), hors du code
  • /healthz « je tourne », /readyz « je peux servir » ; les logs en JSON sur la sortie standard
